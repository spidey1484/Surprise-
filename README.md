# Dholu — One Year Anniversary Website

This is a GitHub Pages-ready website. The personalized names and background instrumental are already included.

## Upload to GitHub Pages

1. Create a new GitHub repository.
2. Upload every file from this folder to the repository's top level: `index.html`, `style.css`, `script.js`, and `song.mp3`.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and the `/ (root)` folder.
4. GitHub will show you the website link. Open it on a phone and tap **Sound On** to play the instrumental.

Keep all four files together. `song.mp3` must remain beside `index.html` for the music button to work.
